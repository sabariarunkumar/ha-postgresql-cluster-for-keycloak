# HA Postgresql Cluster Setup For Keycloak 


Delve into the architecture of High Availability PostgreSQL setup [Single-Master-Multiple-Slave] and the strategic integration with Keycloak for seamless operation in dynamic environments.
In Short, Failover/fallback is handled at DB end and the event is being sent to Client application, followed by employing necessary steps at client side.
